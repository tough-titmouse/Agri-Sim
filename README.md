# Agri-Sim

<img width="1513" height="786" alt="Agri-Sim agricultural greenhouse simulation platform" src="https://github.com/user-attachments/assets/d0048aed-5700-428b-8856-f31f769d11ec" />

Agri-Sim is an agricultural embodied-intelligence virtual training platform developed with Unity and ROS 2.

## Features

- Agricultural greenhouse simulation
- Mobile manipulation robot
- Navigation and manipulation tasks
- RGB-D camera, LiDAR and IMU simulation
- Unity–ROS 2 communication
- Embodied-intelligence training and evaluation

## System Requirements

- Ubuntu 22.04
- x86_64 processor
- Dedicated NVIDIA GPU recommended
- ROS 2 Humble for ROS communication features

## Download

The current testing release is:

**Agri-Sim v0.5.1 – Ubuntu x86_64**

Download it from the [v0.5.1 release page](https://github.com/tough-titmouse/Agri-Sim/releases/tag/v0.5.1).

## Installation and Run

Extract the downloaded package:

```bash
tar -xzvf AgriSim-v0.5.1-Ubuntu-x86_64.tar.gz
```

Enter the extracted directory and start Agri-Sim:

```bash
cd Agri-sim
chmod +x AgriSim-v0.5.1-Ubuntu-x86_64.x86_64
./AgriSim-v0.5.1-Ubuntu-x86_64.x86_64
```
