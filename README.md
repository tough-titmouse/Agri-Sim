# Agri-Sim

Agri-Sim is an agricultural embodied-intelligence virtual training
platform developed with Unity and ROS 2.

## Features

- Agricultural greenhouse simulation
- Mobile manipulation robot
- Navigation and manipulation tasks
- RGB-D camera, LiDAR and IMU simulation
- Unity–ROS 2 communication
- Embodied-intelligence training and evaluation

## System requirements

- Ubuntu 22.04
- x86_64 processor
- Dedicated NVIDIA GPU recommended
- ROS 2 Humble for ROS communication

## Download

Download the latest Ubuntu build from the
[Releases](../../releases/latest) page.
